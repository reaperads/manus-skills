# EVM Address Mechanics & Fund Recovery

## CREATE Address Determinism

```
address = keccak256(rlp(sender, nonce))[12:]
```

- **Sender**: deployer address (EOA or contract)
- **Nonce**: how many times sender has transacted
- **Result**: deterministic — same sender + nonce = same address, ALWAYS

### Predicting Contract Addresses
- Deployer address: visible on Etherscan
- Nonce: trackable from tx history
- Alamat kontrak **BISA DIPREDICT** sebelum tx di-submit
- MEV bots exploit this: pre-fund predicted addresses before deployment

### CREATE2 (Deterministic)
```
address = keccak256(0xff ++ deployer ++ salt ++ keccak256(bytecode))[12:]
```
- Deployer + salt + bytecode = fixed address
- Used by factories (Uniswap V2 pair creation, etc.)
- Address can be calculated before contract exists

## Selfdestruct Recycling

### Pre-Dencun (before March 2024)
1. Contract deployed via CREATE2 at address 0xABC
2. Contract has 10 ETH balance
3. `selfdestruct()` called → code deleted, ETH stuck at 0xABC
4. Address becomes "ghost" — no code, but balance remains
5. New contract deployed to same address → inherits ETH

### Post-Dencun (EIP-6780, March 2024)
- `selfdestruct` only works if called in SAME tx as CREATE
- If called in separate tx → code NOT deleted, only balance sent
- "Ghost addresses" much rarer post-Dencun

## Address Collision Probability

### Space Sizes
| Chain | Address Space | Size |
|-------|--------------|------|
| ETH/BNB/Polygon | 2^160 | 1.46 × 10^48 |
| Bitcoin | 2^160 | 1.46 × 10^48 |
| Solana | 2^256 | 1.16 × 10^77 |

### Why Random Wallet Generation Can't Find Funded Addresses
- 1 wallet = 1 address
- Collision chance = 1/2^160 ≈ 0.000...0% (30+ zeros)
- Even 1 billion wallets = 10^-30 collision chance
- Brute force 2^160 = 10^24 years (100 trillion × universe age)

### Vanity Address Collision
- Vanity = custom pattern (e.g., 0xBEEF...)
- Generated by brute-forcing private keys until pattern matches
- `0xABC123...` ≠ `0xABC456...` — address similarity ≠ same address
- Cannot target specific existing addresses
- Tools: Profanity (GPU, ~1B keys/sec), VanitySearch

## Claimable vs Non-Claimable

### Claimable (theoretically)
- Pre-Dencun ghost addresses (code deleted, ETH stuck)
- Need EXACT CREATE2 parameters: deployer + salt + bytecode
- Or EXACT CREATE parameters: sender + nonce
- If parameters known → usually already claimed by owner

### Non-Claimable
- EOA addresses (need private key — 2^160 space)
- Post-Dencun contracts (code still exists → CREATE fails)
- Known metamorphic (Axelar, Revest — they know the params)

## Practical Fund Recovery Assessment
- Ghost addresses exist and are claimable IF you have exact params
- Most are either already claimed or have tiny balances (dust)
- Gas fees for brute-force salt often exceed recoverable value
- Only worth pursuing for whale addresses (10+ ETH)
